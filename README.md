🧮 // Calculadora de Consumo de Combustível

- Sistema simples em JavaScript que calcula o consumo de um veículo e avalia seu desempenho com base no tipo de combustível.

🚀 // Funcionalidades:

-- Entrada de dados do motorista

-- Seleção do tipo de combustível:
1. Gasolina
2. Etanol
3. Diesel

-- Cálculo de consumo (km/L)

-- Avaliação automática:
Excelente
Regular
Ruim
Crítico

-- Status do veículo:
Liberado para frota
Encaminhado para revisão

🛠️ // Tecnologias utilizadas:

JavaScript

📥 // Como executar:

Você pode rodar o código em:
Navegador (console)
Programiz Online Compiler
Visual Studio Code

📊 // Exemplo de uso:
-- Nome do motorista: João
Tipo de combustível: 1
Distância percorrida: 120
Litros abastecidos: 10
-- Saída:
Consumo: 12.00 km/L
Avaliação: Regular
Status: LIBERADO PARA FROTA

⚠️ // Observações
-- O sistema valida o tipo de combustível
-- A avaliação é baseada em médias esperadas por combustível
